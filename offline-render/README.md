# 离线渲染备选路线

独立入口：`/offline.html`。保留现有实时六幕网站。

先以第三层斗栱制作一段 1.5 秒、24 帧/秒的连续近景样片。镜头沿真实三维路径移动，网页把滚动位置映射到视频时间；向上滚动可以倒放。滑块也能控制位置，无需自动播放权限。手机完整展示横向画面，避免裁掉斗栱。

## 画面

- Blender Cycles：视频 960 × 540、48 采样；静帧预览 1280 × 720、96 采样、自适应采样、去噪、8 次光线反弹。
- 木材沿用已有真实贴图，叠加高度凹凸和微倒角。
- 暖侧光、弱冷补光与檐口反光，使用真实接触阴影和反弹光。
- 视频每帧均为可直接定位的关键帧，优先保障来回滚动定位。代价是比普通长视频更大。

另附 1920 × 1080、128 采样的静帧（第 18 帧），用于检查木纹与阴影细节。网页提供单独打开入口。

这是一段质量与交互验证样片，并非六幕完整离线成片，也不代表原设计稿已经完全还原。增加采样不能修复错误的构件接缝；这些仍须修改模型。去噪可能产生轻微帧间纹理变化，应在制作长片前检查。

## 重现

在仓库根目录执行：

```sh
# 从原始环境精修模型创建场景（本地保有原始模型时）
/Applications/Blender.app/Contents/MacOS/Blender -b --python offline-render/render.py

# 或直接从已保存的样片场景重新逐帧渲染
/Applications/Blender.app/Contents/MacOS/Blender -b offline-render/斗栱离线样片.blend -o //frames/#### -a

# 编码成网页视频和封面（需安装 ffmpeg）
sh offline-render/encode.sh

cd yingxian-pagoda
npm install
npm run build
```

如需更高清版本，可加 `-- --final` 输出 1920 × 1080、192 采样；该规格尚未批量渲染，现有视频明确为小尺寸验证片。高清帧保存在独立的 `frames-final`，编码时运行 `sh offline-render/encode.sh offline-render/frames-final`，尺寸自动读取。

默认使用处理器渲染。本机显卡后端启动未正常推进，因此没有把显卡加速写成已验证能力。场景和素材已打包；单帧图片只留本地，不提交全部中间文件。

后续扩展到六幕时，应先确认各幕镜头与模型，再连续渲染转场，并按片段预加载。小样片先完整载入为本地视频对象，兼容不支持分段读取的静态服务器；长片不应直接照搬这一策略，需使用支持分段请求的托管与章节预加载。

文字继续保留在网页，避免视频中文字模糊以及手机适配困难。

实际模型仍有需要继续修整的地方，例如局部木构接缝、端面纹理方向和过于规则的彩画。此次保存为备选路线，不把换引擎等同于完成精细修模。
