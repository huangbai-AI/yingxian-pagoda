# 斗栱质感精修

与第一轮离线样片分开保存，原实时版不改。

本轮采用恢复后的取景方向，沿构件长轴重新铺设木纹，给长条木材端面分配独立年轮材质，降低过强的表面凹凸，并为彩画增加细微磨损。暖侧光增大光源面积，弱冷补光保留暗部层次。

这次没有切割或删除实体几何。构件形状和连接仍继承原模型；材质与灯光的改善不等同于完成建筑细部考据和榫接重建。

制作脚本：上一级 `refine.py`。从保存的旧样片副本重建，不覆盖原始建模文件。默认输出 1920×1080、128 采样高清首帧；加 `-- --animation` 可输出 960×540、48 采样、36 帧连续镜头。

画面对照入口 `/material-study.html`，保留上一版和原设计稿供切换。旧样片镜头方向不同，因此不是只改变材质的严格对照实验。

本轮连续视频仍采用小尺寸样片，高清细节由独立1080p静帧展示。上一版视频入口 `/offline-original.html`；这一版 `/offline.html`。

核对结果：原版与精修版的 664394 个顶点坐标校验完全一致；已打包 7 张图像，无缺失外部贴图。长构件木纹定向 520 组，独立端面材质应用到 1040 个面。

编码脚本：`sh offline-render/encode-refined.sh`。本轮最终高清静帧使用 `detail-final.png`，视频中间帧位于 `refined/frames`。
