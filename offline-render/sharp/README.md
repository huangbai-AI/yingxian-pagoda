# 原生高清与适度景深

用户希望保留景深，因此最终版本仍开启景深，焦点保持在主斗栱，光圈为 f/8。关闭景深的测试帧只用于排查，未用于新视频。

上一版问题：960×540 视频全屏放大，细节分辨率不足。本版全部 36 帧以 1920×1080 原生渲染，96 采样，自适应阈值 0.018，固定采样种子，24 帧/秒，时长 1.5 秒。编码没有放大模型画面，只将背景合成到对应大小；H.264 每帧关键帧，CRF 14。

保留现有几何倒角，移除额外的着色倒角节点后，本机 Metal 显卡路径已实际出图。场景保存到本目录，可继续编辑。不是用锐化滤镜伪装分辨率提升。

制作：`Blender -b --python offline-render/sharpen.py`，随后 `sh offline-render/encode-hd.sh`。脚本默认使用本机 Apple Metal 设备；其他平台须选择对应渲染设备。

最新入口 `/offline.html?v=5`；上一版 540p 保留在 `/offline-540.html`。`/material-study.html?v=5` 用两版的真实首帧作对照，同时保留原设计稿。
