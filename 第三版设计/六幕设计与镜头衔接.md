# 应县木塔 · 第三版六幕设计

顺序：整塔 → 斜向拆层 → 单层柱网 → 斗栱特写 → 归位飞檐 → 完整全景。

本轮重新生成第 2–6 张，第一张沿用。以下是视觉关键帧设计，尚非网页或实际模型渲染验证。

## 连续镜头约束

- 全程沿同一可见塔角推进、退回，避免跨过塔心或突然换面。
- 第二幕仅作有虚线引导的受控拆层；正常整塔状态与第五、六幕必须完整接触。
- 第三幕固定目标楼层，第四幕固定该楼层的同一柱头；不得换成结构不同的独立标本。
- 第四幕到第五幕先归位后拉远，构件从原路径返回；不能靠淡入一座不同的塔替代组装。
- 相邻镜头的移动速度连续，转向前逐渐减速；滚动反向时可沿原路径复原。
- 统一墨绿背景、右上暖光和木色，场景氛围变化随远近发生。
- 文本保持水平，不跟随拆解模型倾斜；详细知识放到按需展开内容。

## 实现核对

生成图用于构图与气氛参考。实际制作必须用同一套模型锁定楼层尺寸、24 外槽柱与 8 内槽柱、五层六檐、斗栱接触和构件身份，不能把图中可能出现的数量或连接误差照搬到模型。木纹与光影需用实际近景渲染验证。环境为氛围示意，不作为佛宫寺现状测绘复原。
