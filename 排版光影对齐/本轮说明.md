# 第十版：光影与排版

按「第三版设计」六张确认稿逐页调整。

- 光影：降低环境光和无阴影补光，保留明确的暖色主光；斗栱近景降低灯位，避免屋檐挡住主光。瓦面适当提亮，木纹凹凸更克制。
- 背景：压低中间篇章泛白的雾光，保留墨青渐变和主体背后的亮度层次。
- 文字：第二、三幕文字移到原稿对应的右侧位置，重新校准标题字号、行距、正文间隔；第四、五、六幕分别校准标题与段落位置。手机移除斗栱文字区域的方形底色。
- 对照：网站 alignment.html 提供六幕原稿、修改前与本轮实际截图。quality.html 标为第九版存档。

验证：生产构建通过；1672×940 桌面、390×844 手机六幕截图检查；手机文字无横向溢出；自由观塔进出、滚动返回首屏正常；原稿与前后截图切换正常。附检查记录。

保留的差异：建筑比例、斗栱形体、瓦面和实物纹理尚未达到生成设计稿的细节程度。本轮调整没有改变模型几何，也没有生成完整预渲染滚动序列。GitHub 的 v9 附件保留第九版，最新网站源码位于 main 分支。
